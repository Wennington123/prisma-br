# Tabela 1 — Itens da lista de checagem PRISMA 2020

Fonte: Declaração PRISMA 2020 (pt-BR), Page MJ et al., *Epidemiologia e Serviços de
Saúde* 2022;31(2):e2022107, Tabela 1. Texto oficial — usar sem parafrasear.

## Título

**Título — Item 1**
Identifique a publicação como uma revisão sistemática.

## Resumo

**Resumo — Item 2**
Veja a lista de checagem PRISMA 2020 para Resumos (ver `checklist-resumo.md`).

## Introdução

**Justificativa — Item 3**
Descreva a justificativa da revisão no contexto do que já é conhecido.

**Objetivos — Item 4**
Apresente uma afirmação explícita dos objetivos ou questões abordadas pela revisão.

## Métodos

**Critérios de elegibilidade — Item 5**
Especifique critérios de inclusão e exclusão da revisão e como os estudos foram
agrupados nas sumarizações.

**Fontes de informação — Item 6**
Especifique todas as bases de dados, repositórios de registros, sites, organizações,
listas de referências e outras fontes pesquisadas ou consultadas para identificar
estudos. Especifique a data em que cada fonte foi pesquisada ou consultada pela
última vez.

**Estratégia de busca — Item 7**
Apresente as estratégias de busca completas para todas as bases de dados,
repositórios de registros e sites, incluindo filtros ou limites usados.

**Processo de seleção — Item 8**
Especifique os métodos usados para decidir se um estudo atendeu aos critérios de
inclusão da revisão, incluindo quantos revisores selecionaram cada registro e
publicação recuperados, se trabalharam de forma independente e, se aplicável,
detalhes de ferramentas de automação utilizadas no processo.

**Processo de coleta de dados — Item 9**
Especifique os métodos usados para coletar dados das publicações, incluindo quantos
revisores coletaram dados de cada publicação, se eles trabalharam de forma
independente, quaisquer processos para obter ou confirmar dados com os autores do
estudo e, se aplicável, detalhes de ferramentas de automação utilizadas no processo.

**Lista de dados — Item 10a**
Liste e defina todos os desfechos cujos dados foram coletados. Especifique se foram
coletados de cada estudo todos os resultados compatíveis com cada domínio de
desfecho (ex.: para todas as medidas, ponto de tempo, análises), e se não, quais os
métodos usados para decidir quais resultados coletar.

**Lista de dados — Item 10b**
Liste e defina todas as outras variáveis cujos dados foram coletados (ex.:
características dos participantes e da intervenção, fontes de financiamento).
Descreva pressupostos adotados para casos de informações faltantes ou pouco claras.

**Avaliação do risco de viés dos estudos — Item 11**
Especifique os métodos usados para avaliar o risco de viés nos estudos incluídos,
incluindo detalhes da(s) ferramenta(s) usada(s), quantos revisores avaliaram cada
estudo e se trabalharam de forma independente e, se aplicável, detalhes de
ferramentas de automação usadas no processo.

**Medidas de efeito — Item 12**
Especifique para cada desfecho a(s) medida(s) de efeito (ex.: risco relativo,
diferença de médias) usadas na sumarização ou apresentação dos resultados.

**Métodos de síntese — Item 13a**
Descreva os processos usados para decidir quais estudos foram elegíveis para cada
síntese [ex.: tabulação das características da intervenção do estudo e comparação
com os grupos planejados para cada sumarização (item 5)].

**Métodos de síntese — Item 13b**
Descreva métodos demandados para preparar os dados para apresentação ou síntese,
como manejo de dados faltantes nas estatísticas de sumarização ou conversões de
dados.

**Métodos de síntese — Item 13c**
Descreva métodos usados para tabular ou ilustrar visualmente os resultados de
estudos individuais e sínteses.

**Métodos de síntese — Item 13d**
Descreva métodos usados para sumarizar os resultados e apresente justificativa para
a(s) escolha(s). Se uma meta-análise foi realizada, descreva o(s) modelo(s),
método(s) para identificar a presença e extensão da heterogeneidade estatística e o(s)
pacote(s) de software utilizado(s).

**Métodos de síntese — Item 13e**
Descreva métodos usados para explorar as possíveis causas de heterogeneidade entre
os resultados dos estudos (ex.: análise de subgrupo, metarregressão).

**Métodos de síntese — Item 13f**
Descreva análises de sensibilidade conduzidas para avaliar a robustez dos resultados
sumarizados.

**Avaliação de vieses de publicação — Item 14**
Descreva métodos usados para avaliar o risco de viés devido a resultados faltantes
em uma sumarização (decorrente de vieses de publicação).

**Avaliação da certeza — Item 15**
Descreva métodos usados para avaliar a certeza (ou confiança) no corpo de evidências
de um desfecho.

## Resultados

**Seleção dos estudos — Item 16a**
Descreva os resultados do processo de busca e seleção, desde o número de registros
identificados na busca até o número de estudos incluídos na revisão, idealmente por
meio de um fluxograma.

**Seleção dos estudos — Item 16b**
Cite estudos que parecem cumprir os critérios de inclusão, mas que foram excluídos e
explique por que foram excluídos.

**Características dos estudos — Item 17**
Cite cada estudo incluído e apresente suas características.

**Risco de viés nos estudos — Item 18**
Apresente as avaliações do risco de viés de cada estudo incluído.

**Resultados de estudos individuais — Item 19**
Para todos os desfechos, apresente para cada estudo: (a) estatística sumária para
cada grupo (quando apropriado) e (b) estimativa de efeito e sua precisão (ex.:
intervalo de confiança/credibilidade), idealmente utilizando tabelas estruturadas ou
gráficos.

**Resultados das sínteses — Item 20a**
Para cada síntese, resuma brevemente as características e o risco de viés entre os
estudos contribuintes.

**Resultados das sínteses — Item 20b**
Apresente os resultados de todas as sumarizações estatísticas realizadas. Se
meta-análises foram feitas, apresente para cada uma a estimativa resumida e sua
precisão (por exemplo, intervalo de confiança/credibilidade) e medidas de
heterogeneidade estatística. Se estiver comparando grupos, descreva a direção do
efeito.

**Resultados das sínteses — Item 20c**
Apresente os resultados de todas as investigações das possíveis causas de
heterogeneidade entre os resultados do estudo.

**Resultados das sínteses — Item 20d**
Apresente os resultados de todas as análises de sensibilidade conduzidas para
avaliar a robustez dos resultados sumarizados.

**Vieses de publicação — Item 21**
Apresente avaliações de risco de viés devido a resultados faltantes (decorrentes de
vieses de publicação) para cada sumarização avaliada.

**Certeza da evidência — Item 22**
Apresente avaliações da certeza (ou confiança) no corpo de evidências para cada
desfecho avaliado.

## Discussão

**Discussão — Item 23a**
Forneça uma interpretação geral dos resultados no contexto de outras evidências.

**Discussão — Item 23b**
Discuta limitações das evidências incluídas na revisão.

**Discussão — Item 23c**
Discuta limitações dos processos empregados na revisão.

**Discussão — Item 23d**
Discuta as implicações dos resultados para a prática, política e pesquisas futuras.

## Outras informações

**Registro e protocolo — Item 24a**
Forneça informações de registro da revisão, incluindo o nome do repositório e o
número de registro, ou declare que a revisão não foi registrada.

**Registro e protocolo — Item 24b**
Indique onde o protocolo de revisão pode ser acessado ou indique se o protocolo não
foi preparado.

**Registro e protocolo — Item 24c**
Descreva e explique quaisquer alterações nas informações fornecidas no registro ou
no protocolo.

**Apoio — Item 25**
Descreva as fontes de apoio financeiro ou não financeiro para a revisão e o papel
dos financiadores ou patrocinadores na revisão.

**Conflito de interesses — Item 26**
Declare quaisquer conflitos de interesse dos autores da revisão.

**Disponibilidade de dados, código e outros materiais — Item 27**
Relate quais dos itens a seguir estão disponíveis publicamente e onde podem ser
encontrados: modelos de formulários para coleta de dados; dados extraídos dos
estudos incluídos; dados usados para todas as análises; comando analítico; outros
materiais usados na revisão.
